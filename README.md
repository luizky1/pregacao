# PREGAÇÃO — Assistente de Roteiros Católicos

Aplicativo Vite + React + Tailwind CSS + Lucide React, mobile-first.

## Rodar localmente

```bash
npm install
npm run dev
```

## Gerar build

```bash
npm run build
npm run preview
```

## GitHub

```bash
git init
git add .
git commit -m "Primeiro commit: Aplicativo PREGAÇÃO Católico"
git branch -M main
git remote add origin https://github.com/SEU_USUARIO_GITHUB/pregacao.git
git push -u origin main
```

## Vercel

Importe o repositório no Vercel. Framework: Vite. Build: `npm run build`. Output: `dist`.

## Observação

O projeto inclui as 10 etapas, Oratório do Pregador, Modo Púlpito, Tratado dos Sete Dons e salvamento local do roteiro no navegador.
